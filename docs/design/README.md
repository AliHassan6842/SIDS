# Design reference

`sids-mobile-concept.png` is a visual direction board generated before the dataset audit completed. Its pale mint/forest-green camera-first layout, large touch targets, ROI guide, result hierarchy, and bottom navigation informed the implementation.

The sample Cotton labels and example insects in that board are illustrative only and are not product or model claims. The implemented catalog is API-driven and the final supported scope is Rice plus the three classes listed in `docs/ai/FINAL_DATASET_SCOPE.md`.
