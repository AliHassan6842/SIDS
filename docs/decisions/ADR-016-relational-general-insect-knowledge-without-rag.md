# ADR-016: Keep general-insect knowledge relational and defer RAG

## Status

Accepted — 2026-08-26.

## Context

SIDS needs to identify a bounded set of promoted general-insect groups and return reviewed information about possible harm, safe non-chemical removal, and when expert help is appropriate. The recognition input is an image. The first promoted catalog is expected to contain only a few coarse groups with stable slugs and attributable guidance.

Retrieval-augmented generation and a vector database were considered for this feature. Neither improves visual recognition: classification confidence and out-of-distribution rejection must come from an evaluated vision model. Generating safety guidance at request time would also make results less deterministic and could turn a coarse group prediction into unsupported species-level advice.

## Decision

- The Python AI service performs bounded image classification and returns only a promoted label, confidence evidence, model version, dataset version, or an explicit unknown/rejection result.
- Java resolves the label to a supported catalog row and owns reviewed harm/removal guidance, attribution, authorization, and result persistence.
- PostgreSQL stores the small catalog and guidance as normalized relational data keyed by stable identifiers and slugs.
- Guidance is curated from allowlisted, attributable public-health or extension sources. It is not generated by the model and does not prescribe pesticides or dosages.
- No vector extension, embedding pipeline, language model, or RAG runtime is introduced for the initial general-insect feature.
- If the reviewed catalog later becomes large enough to require natural-language search, PostgreSQL full-text search with a generated `tsvector` column and a GIN index is the first retrieval option. Embeddings may be reconsidered only for a measured semantic-search requirement, never as a substitute for model evaluation or reviewed safety content.

## Consequences

- Image recognition quality remains measurable and versioned independently from guidance retrieval.
- Known results are deterministic, attributable, and fail closed when a promoted label or guidance row is missing.
- Unknown insects do not receive invented names or generalized safety claims.
- The deployment avoids an additional database extension, embedding lifecycle, and generative-model dependency.
- Adding a promoted insect requires coordinated model, contract, catalog, guidance, migration, and end-to-end evidence.
