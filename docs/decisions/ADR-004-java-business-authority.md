# ADR-004: Java owns business authority

- Status: Accepted
- Date: 2026-08-16

## Context

AI evidence must be combined with ownership, field context, surveys, weather, thresholds, history, and verified knowledge.

## Decision

The Java core owns authorization, durable field state, risk interpretation, thresholds, agronomic recommendations, and treatment policy.

## Consequences

Clients and Python services cannot bypass Java policy. AI results remain inputs to a traceable domain decision.
