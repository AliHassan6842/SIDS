# AI role playbooks

These files are playbooks for future, explicitly assigned Codex tasks. They are not automatically discovered subagents; repository-scoped automatic instructions are the `AGENTS.md` files.

An orchestrated task must give each role a bounded path/output, avoid simultaneous ownership of the same files, verify evidence, and stop at its assigned phase. No playbook authorizes frontend edits, dataset/model downloads, production changes, or external publication by itself.
