# Frontend protection

THIS DIRECTORY IS OWNED BY THE FRONTEND TEAM MEMBER.

DO NOT MODIFY ANY FILE UNDER `apps/web` UNLESS THE USER EXPLICITLY REQUESTS FRONTEND CHANGES.

Inspection is allowed. Build and test commands may be run when they do not rewrite source.

Do not:

- refactor or format code;
- upgrade dependencies or migrate package managers;
- change routes, components, TypeScript, CSS, mocks, or API contracts;
- change `package.json`, lockfiles, tsconfig files, or Vite configuration;
- remove mock data or fix errors during unrelated work.

Only this `AGENTS.md` may be introduced by the F0 foundation task.
